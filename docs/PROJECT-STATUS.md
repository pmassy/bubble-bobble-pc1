# Project status

## Verified

- PC1/Yamaha V6355D 160×200 16-colour mode;
- logical 16-colour encoding into CGA 2bpp pixel pairs;
- `BBLOCKS.CCF` rebuild;
- `SPRITES.CCF` workflow, duplicate detection, reimport, PC1 conversion and masks;
- `TITLEPIC.CCF`, `EXTEND.CCF`, `SECRET.CCF`;
- 160×200 `ARCADE.TCF` with PC1, EGA and Tandy renderers;
- vertical and horizontal shadow patches;
- text-colour and procedural star-field patches;
- invulnerability and initial-level selection;
- `BBCHEAT.ASM`, assembled with TASM 1.0;
- EXEPACK decompression of `BUBBOB.DAT` for static analysis.

A significant part of the modifications was verified on a real Olivetti Prodest PC1.
